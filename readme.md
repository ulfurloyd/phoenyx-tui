# phoenyx-tui

a personal TUI for managing my systems, projects and homelab

built with Go and Bubble Tea

work in progress

## dev

run:
```bash
go run ./cmd/phoenyx
```

build:
```bash
go build ./cmd/phoenyx
```

install (creates `$(go env GOBIN)/phoenyx`):
```bash
go install ./cmd/phoenyx
```
or run `build.sh`
